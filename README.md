# [MazeAhKmao]

> You were kidnapped. Find the exit and escape the maze.

## Objective

Survive the maze and find the exit door before the enemy catches you.
Use your flashlight and find the way to reach the center of the maze to get a checkpoint flag, then find the exit.

## Rules

### Goal
- Find the exit door and escape the maze.

### Health & Death
- You have 15 HP.
- After escaping the enemy, you regenerate 1 HP every 5 seconds.
- You have 3 lives. After your 3rd death, it's game over.
- Use your stamina to to speed up yourself.

### Checkpoint & Respawn
- Reach the center of the maze to pick up the checkpoint flag.
- With the flag, you respawn right in the center of the maze.
- Without the flag, you respawn at the starting point.

### Enemy
- There is only 1 enemy. It cannot be killed.
- It is slower than you but attacks faster.

### Exit Door
- One exit door at the edge of the maze.

### Win / Lose
- **Win:** reach the exit door.
- **Lose:** die 3 times.

## Unity Version

Unity 6000.3.8f1

## Setup (Run from Unity)

1. Clone the repository:
   `git clone [https://github.com/PhalSambathoudom/GameDev_Midterm.git]`
2. Open **Unity Hub** and click **Add project from disk**.
3. Select the cloned folder and open it with the Unity version above.
4. Open the main scene: `Assets/Scenes/[SceneName].unity`
5. Press **Play**.
